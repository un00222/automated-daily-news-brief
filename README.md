# Automated Daily News Brief Pipeline

## Project Overview
An automated data engineering pipeline that collects news articles from REST APIs and RSS feeds, cleans and deduplicates the data, stores it in Parquet format, and generates a daily news brief.

## Tech Stack
- Python
- REST API
- RSS
- DuckDB
- SQL
- Parquet
- GitHub Actions

## Project Goals
1. Extract news from APIs and RSS feeds.
2. Standardize article data.
3. Remove duplicate articles.
4. Store cleaned data in Parquet format.
5. Analyze news using SQL.
6. Generate a daily Markdown news report.
7. Automate the pipeline with GitHub Actions.
